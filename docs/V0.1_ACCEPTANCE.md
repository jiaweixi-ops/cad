# V0.1 Acceptance

## Automated/local checks

Run from `E:\CAD插件开发`:

```powershell
.\tools\verify-v01.ps1
```

The script checks the project skeleton, command names, AutoCAD reference copy policy, Core isolation, and forbidden V0.1 behaviors. It is not a substitute for a real AutoCAD host test.

## Build gate

The AutoCAD 2025 project uses the confirmed local directory `D:\Autodesk\CAD2025\AutoCAD 2025` by default, or `AUTOCAD_MANAGED_API_DIR` when explicitly set. It intentionally fails with a clear error if the three real Managed API assemblies are not present. This prevents accidental builds against missing, guessed, or copied Autodesk DLLs.

The build must produce `CADProjectManager.AutoCAD.dll` without copying `AcMgd.dll`, `AcDbMgd.dll`, or `AcCoreMgd.dll` to the output directory.

## Manual AutoCAD gate

On a machine with the matching AutoCAD version:

1. Close unrelated AutoCAD documents or use a disposable test drawing.
2. Load the built adapter with `NETLOAD`.
3. Run `CADPM_HEALTH` 100 consecutive times and confirm no command exception.
4. Run `CADPM_INFO` and confirm plugin/config/log paths are displayed.
5. Compare the drawing and relevant system variables before/after; no DWG data or system variable may change.
6. Open/close 20 test drawings, create/save/Save As, Undo/Redo, Plot Preview, switch documents, and exit AutoCAD.
7. Confirm the log is under `%LOCALAPPDATA%\CADProjectManager\logs` and a simulated log failure does not terminate AutoCAD.
8. Remove the bundle after closing AutoCAD and verify the next clean session has no plugin residue.

Until these checks are executed in the actual AutoCAD host, V0.1 remains `source-ready / host-unverified`, not `PASS`.

## Core Console smoke test

The repository includes `tools/v01-accoreconsole.scr`. After building, run it against a disposable or Autodesk sample DWG with AutoCAD 2025 `accoreconsole.exe`. The script only loads the DLL, runs the two read-only commands, and quits; it does not save the sample drawing.

```powershell
$stage = 'D:\Temp\CADProjectManager.V0.1'
New-Item -ItemType Directory -Force $stage | Out-Null
Copy-Item '.\src\CADProjectManager.AutoCAD\bin\Debug\net8.0\*.dll' $stage
$core = 'D:\Autodesk\CAD2025\AutoCAD 2025\accoreconsole.exe'
$dwg = 'D:\Autodesk\CAD2025\AutoCAD 2025\Express\brkline.dwg'
& $core /i $dwg /s 'E:\CAD插件开发\tools\v01-accoreconsole-staged.scr'
```

This is still a smoke test. The full GUI lifecycle matrix above remains required before marking V0.1 `PASS`.
